# p1ComplementSeparatedNpuRauToo

Complements the Device object in OperationalDS with hardware and firmware attributes required for a Device of firmwareStructure==separated-npu-and-rau.  

In its current version, the following attributes get added:

- empty [firmware-list] attribute
- empty [controller-firmware-list] attribute
- empty [odu-firmware-list] attribute
