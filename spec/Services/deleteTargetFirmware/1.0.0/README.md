# deleteTargetFirmware

Deletes a FirmwareResource from the targetFirmwareList of a given DeviceGroup.  
Deletes the same firmware from the firmwareList of all Devices referenced by the same DeviceGroup.  

Consequences: The firmware will no longer be attempted to be loaded onto the devices.
